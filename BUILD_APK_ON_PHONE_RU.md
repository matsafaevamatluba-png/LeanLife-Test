# Как собрать APK LeanLife прямо с телефона

## 1. Создай репозиторий
1. Открой https://github.com и войди в аккаунт (или создай его).
2. Нажми **+ → New repository**.
3. Назови репозиторий `LeanLife`, выбери **Public** или **Private**, затем **Create repository**.

## 2. Загрузи файлы проекта
1. Распакуй `LeanLife_Android_Project.zip` на телефоне через приложение «Файлы».
2. В репозитории GitHub нажми **Add file → Upload files**.
3. Загрузи содержимое папки проекта, сохраняя структуру каталогов. Важно: папка `.github/workflows` может быть скрытой в файловом менеджере. Если она не показывается, включи показ скрытых файлов.
4. Проверь, что файл `.github/workflows/android-apk.yml` находится именно по этому пути в репозитории. Можно создать его напрямую на GitHub: **Add file → Create new file**, в поле имени указать `.github/workflows/android-apk.yml`, затем вставить содержимое этого файла из ZIP.

## 3. Запусти сборку
1. Открой вкладку **Actions** репозитория.
2. Если GitHub попросит разрешить workflows, нажми разрешить.
3. Выбери **Build LeanLife APK** и нажми **Run workflow**. Если workflow ещё не отображается, сначала добавь/закоммить файл workflow в ветку `main`.
4. Открой запущенный процесс и дождись завершения. Зелёная галочка означает, что шаги workflow прошли успешно.

## 4. Скачай APK
1. На странице завершённого запуска прокрути вниз до **Artifacts**.
2. Скачай `LeanLife-debug-apk.zip`.
3. Распакуй его: внутри должен быть `app-debug.apk`.
4. Нажми на APK и подтверди установку, если Android спросит разрешение для браузера/файлового менеджера на установку неизвестных приложений.

## Если сборка не прошла
Открой упавший шаг в Actions и посмотри текст ошибки. Это конфигурация для первой попытки сборки; облачная сборка может выявить ошибки кода или совместимости, которые нужно будет исправить. APK не считается готовым, пока workflow не завершится успешно.

## Важно о безопасности
Это debug APK для тестирования, не подписанный релиз для Google Play. Не публикуй его как production-сборку без тестирования, корректной подписи и политики конфиденциальности.
