# LeanLife — Android MVP

Бесплатный Android-прототип на Kotlin + Jetpack Compose. Тема: тёмный фон, зелёные акценты. Все данные сохраняются локально через Preferences DataStore; сервер и аккаунт не требуются.

## Экраны
- Главная: вода, чек-лист дня, краткий совет.
- Питание: локальный журнал приёмов пищи, добавление и очистка записей.
- Активность: прогулка, танцы, растяжка, велосипед или отдых.
- Привычки: чек-лист здоровых привычек.
- Профиль: имя для приветствия, информация о приватности и сброс данных.

## Требования
- Android Studio (актуальная стабильная версия)
- JDK 17
- Android SDK 35; Gradle Wrapper рекомендуется создать через Android Studio
- Для установки на телефон: включить параметры разработчика/USB debugging при запуске с компьютера либо собрать APK.

## Запуск
1. Распакуйте проект.
2. В Android Studio выберите **Open** и укажите папку `LeanLife`.
3. Дождитесь Gradle Sync. Если Android Studio предложит установить Android SDK 35 — согласитесь.
4. Создайте Gradle Wrapper из меню Android Studio либо выполните `gradle wrapper` при установленном Gradle.
5. Подключите Android-телефон с USB debugging или создайте эмулятор.
6. Нажмите **Run** (зелёный треугольник).
7. Для APK: **Build → Build APK(s)**. Debug APK обычно создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

## Архитектура MVP
- UI: single-activity Jetpack Compose + Material 3.
- Логика экранов: `Page` enum и состояния Compose.
- Хранение: Preferences DataStore; вода, привычки и журнал питания сохраняются после закрытия.
- Без сети: в манифесте не запрашиваются интернет-разрешения.
- Без рекламы, аккаунтов и платных функций.

## Ограничения текущего MVP
- Это исходный проект, а не уже собранный и протестированный APK.
- Пока нет облачной синхронизации, базы продуктов/штрихкодов, подсчёта калорий, рецептов из внешних источников, уведомлений, Health Connect, экспорта данных и автоматических тестов.
- Отметка активности и имя профиля пока находятся в памяти экрана; журнал питания, вода и привычки сохраняются локально.
- Перед публикацией нужны сборка и тестирование на реальном устройстве, accessibility-проверка, политика конфиденциальности и ревью медицинских формулировок.

## Принципы безопасности
Не использовать голодание, экстремальные ограничения, «цели веса» для несовершеннолетних или стыдящие формулировки. Не представлять приблизительные оценки как медицинские факты. По вопросам веса и здоровья обращаться к квалифицированному специалисту.
